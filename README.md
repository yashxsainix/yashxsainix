## 🧠 The Story

My father ran a small business with a notebook and a gut feeling. No dashboards. No reports. Just instinct and hope. It worked until it didn't.

That's when I started caring about data — not because I loved spreadsheets, but because I saw what happens when real decisions get made without real information underneath them.

That curiosity brought me from India to New York, through two years as a Data Analyst at **I3 Infosoft**, and eventually to the **Research Foundation of CUNY** where I now maintain data pipelines across 26 university campuses. The question I've been chasing the whole time is the same one: *what does the data actually say — and does anyone trust it enough to act on it?*

I build things before being asked to. The GA4 Dataform pipeline on my GitHub mirrors the exact Apache Iceberg lakehouse architecture used in production data platforms. The MTA transit pipeline was built on public data with free tools because the analytical layer simply did not exist. That is how I approach problems.

> *"The data existed. Nobody trusted it. I fixed that."*
